The goal of this project is to develop a cross-\/platform application to enhance monitoring of local environmental conditions. There are three categories of environmental data that will be monitoried
\begin{DoxyItemize}
\item Air Quality
\item Water Quality
\item Weather Conditions
\end{DoxyItemize}\hypertarget{md__r_e_a_d_m_e_autotoc_md4}{}\doxysubsubsection{\texorpdfstring{Requirements}{Requirements}}\label{md__r_e_a_d_m_e_autotoc_md4}
According to the Environmental Scientist, the application will be required to\+:
\begin{DoxyItemize}
\item Manage sensor accounts and configure settings.
\item View and analyse historical environmental data.
\item Receive real-\/time alerts on threshold breaches, displayed on an interactive map
\item Generate comprehensive reports on environmental trends.
\item Use a map to view real-\/time sensor statuses and alerts geographically.
\item Locate and navigate to sensors in the field for maintenance or inspection purposes.
\end{DoxyItemize}

According to the Operations Manager, the application will be required to\+:
\begin{DoxyItemize}
\item Monitor the operational status of sensors.
\item Schedule maintenance and ensure timely checks.
\item Verify the accuracy and integrity of collected data.
\item Address and report sensor malfunctions or anomalies.
\end{DoxyItemize}

According to the Administrator, the application will be required to\+:
\begin{DoxyItemize}
\item Manage user access and roles within the application.
\item Maintain high levels of system security and data protection.
\item Update sensor configurations and firmware.
\item Oversee data storage and implement backup strategies.
\end{DoxyItemize}\hypertarget{md__r_e_a_d_m_e_autotoc_md5}{}\doxysubsubsection{\texorpdfstring{Technologies}{Technologies}}\label{md__r_e_a_d_m_e_autotoc_md5}
This application will be built in C\# MAUI to enable cross-\/platform operation. Data management will be handled by a SQL Server database, with provided example datasets.
